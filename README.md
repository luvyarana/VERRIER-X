# VERRIER-X

A web tool for watching the sky change in NASA SPHEREx images.
Built for the NASA Space Apps Challenge 2026: [Planet X and SPHEREx](https://www.spaceappschallenge.org/2026/challenges/planet-x-and-spherex/).

Enter a sky position (Right Ascension and Declination) and VERRIER-X plays the SPHEREx images of that patch as a short movie, so that moving and changing objects stand out.

**Status:** planning. See [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).

## Data credit

This project uses data products from the Spectro-Photometer for the History of the Universe, Epoch of Reionization and Ices Explorer (SPHEREx), which is a joint project of the Jet Propulsion Laboratory and the California Institute of Technology, and is funded by the National Aeronautics and Space Administration. Data are served by the NASA/IPAC Infrared Science Archive (IRSA).
